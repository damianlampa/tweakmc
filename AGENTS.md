# Praca z projektem TweakMC

Przed rozpoczęciem pracy przeczytaj także `AGENTS.md.local`, jeśli istnieje.

- Korzystaj z Node.js wskazanego w `.nvmrc` i npm z `packageManager`. Instaluj zależności przez `npm ci`.
- Uruchom aplikację poleceniem `npm run dev`. Kod React, style Tailwind i sceny Three.js znajdują się w `src/`. Zachowuj istniejący podział katalogów i nazwy plików w kebab-case.
- Uruchom `npm run check` i `npm run build` przed oddaniem zmiany. Przy modyfikacjach interfejsu sprawdź też `npm test` oraz nawigację klawiaturą.
- Stosuj Conventional Commits dla commitów i tytułów PR. W opisie PR podaj cel zmiany i wyniki weryfikacji.
